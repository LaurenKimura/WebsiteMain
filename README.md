# Lauren's Personal Website

Built With: 
React 18 (JSX, not TypeScript)
Vite 5 as the bundler and dev server
3D / animation

Three.js for WebGL
React Three Fiber (@react-three/fiber) to use Three.js in React
Drei (@react-three/drei) for Three.js helpers
Motion for UI animation
react-type-animation for the typing effect
Styling

Plain CSS files per section (home.css, contact.css, etc.) — no Tailwind, Sass, or CSS-in-JS
Tooling

ESLint with the React and React Three plugins

inspired by Lama Dev Animated 3D Project
